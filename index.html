The Idea

THE BOX

Multiple identities. One experience.

In an Indian kitchen the masala box keeps each spice in its own compartment so it stays true. Close the lid and it becomes one object, ready for any dish. Spice Box Co. is built the same way: distinct culinary influences, each curated on its own terms, brought together under one lid.
